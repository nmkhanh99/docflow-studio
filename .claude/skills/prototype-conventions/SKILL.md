Kiểm tra docs/DocFlow_Interactive_Mockup.html trước khi đổi hành vi. File chứa CSS inline, JavaScript thuần với state, view dạng chuỗi template và handler window.app. Giữ văn bản tiếng Việt, định dạng vi-VN, CSS token, breakpoint responsive và việc escape văn bản động. Coi 4 file docs/mockup_*.png là tham chiếu hình ảnh. Không có framework, package manager hay lệnh test tự động. Tách kiến trúc production đề xuất khỏi năng lực hiện có.
